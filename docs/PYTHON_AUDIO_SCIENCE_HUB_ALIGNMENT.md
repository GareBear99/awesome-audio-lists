# Python Audio Science Hub Alignment

This document records the hub update that adds `GareBear99/awesome-python-audio-science` as a canonical satellite of `awesome-audio-lists`.

## Canonical repo

- Repo: https://github.com/GareBear99/awesome-python-audio-science
- Display title: Awesome Python Audio Science
- Role: Python scientific audio, MIR, DSP, machine-learning audio, datasets, notebooks, plugin analysis, and creator-audio automation.

## Why it belongs in the hub

`awesome-audio-lists` is the root map for audio discovery surfaces. `awesome-python-audio-science` fills the research/tooling lane that sits between audio DSP, plugin testing, Voxel Audio automation, deconstructed-loop analysis, and FreeEQ8/FreeVox8 validation notebooks.

## Required cross-links

Every satellite should preserve links to:

- `awesome-audio-lists` as the parent hub.
- `awesome-music-platforms` as the artist/distribution map.
- `awesome-audio-plugins-dev` as the plugin/dev map.
- `TizWildinEntertainmentHUB` as the public `.io` router.
- `TizWildin-Release-Vault` as the release/catalog proof surface.
- `FreeEQ8` and `FreeVox8` as plugin anchors.
- `Voxel_Audio` as the visualizer/router/export anchor.
