# Hub Linking Strategy

`awesome-audio-lists` is the root discovery hub for the GareBear99 / TizWildin audio ecosystem.

## Naming rule

- Repo names: lowercase and hyphenated.
- README titles: capitalized and readable.
- GitHub topics: lowercase.

Recommended names:

| Purpose | Repo name | README title |
|---|---|---|
| Root hub | `awesome-audio-lists` | `Awesome Audio Lists` |
| Plugin/dev list | `awesome-audio-plugins-dev` | `Awesome Audio Plugins Dev` |
| Music platform list | `awesome-music-platforms` | `Awesome Music Platforms` |

## Link graph

```text
awesome-audio-lists
├─ awesome-audio-plugins-dev
├─ awesome-music-platforms
├─ FreeEQ8 / FreeVox8 / plugin repos
├─ Voxel Audio / visualizer tools
└─ TizWildin music, sample packs, release vault, SoundCloud, YouTube, Facebook
```

## What belongs in each repo

### awesome-audio-lists
Use for curated lists, submission targets, plugin directories, sample-pack directories, audio engineering lists, JUCE/WebAudio/DSP lists, and ecosystem routing.

### awesome-audio-plugins-dev
Use for audio plugins, open-source DSP tools, plugin-development resources, JUCE projects, VST/AU/CLAP/LV2 resources, and plugin ecosystem visibility.

### awesome-music-platforms
Use for streaming platforms, distribution services, sample-pack marketplaces, beat stores, sync licensing, music promotion, analytics, creator storefronts, communities, and music visualization platforms.

## SEO guidance

Every satellite should link back to this hub with language like:

> Part of the GareBear99 / TizWildin audio discovery network. See `awesome-audio-lists` for the root hub of audio lists, plugin directories, sample-pack directories, and music-platform submission targets.

Every product repo should link to at least one relevant satellite and the root hub.
